## 查看历史版本

完成提交、标签和上传后，可在 GitHub 中切换标签查看对应版本。下载某个标签的 ZIP 并解压后，在该目录运行 `node preview.cjs`，然后浏览 `http://127.0.0.1:4174/`。先停止其他占用该端口的预览。

早期单文件首页可以直接用浏览器打开 `versions/homepage-initial/index.html`。

## 范围说明

- 原始项目图片、生活照片、字体、页面代码和交互脚本随原有历史保留。
- 保留已有提交，不修改原有提交的时间或作者，也不将无法确认的中间状态伪造成历史版本。
- 临时发布凭证、发布压缩包、工具运行文件不纳入版本档案。
- 网站在线发布与 GitHub 版本备份是两件独立的事。GitHub 中的最新代码不代表线上网站已更新。
